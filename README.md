•	This application consists of two modules
o	Admin module
o	Public user module
•	The admin module functionalities
o	Creating study subjects (e.g.  Math, Physics,…)
o	Creating multiple choice questions with difficulty levels
o	Configure examination difficulty level
o	For example if exam if hard and consists of 5 questions then pick  3 hard questions ,1 medium level  and 1 easy 
o	The above may vary as per user request
•	Public user module
o	Register
o	Take     exams according to difficulty level they choose.
	The exam questions will appear as per admin configuration
